# aminmsalimi.github.io

Complete standalone GitHub Pages portfolio for Amin Salimi.

## Included files

- `index.html`
- `styles.css`
- `script.js`
- `favicon.svg`
- `profile.jpg`
- `Amin-Salimi-CV.pdf`
- `README.md`

## Local preview

From this folder:

```powershell
python -m http.server 8000
```

Open:

```text
http://localhost:8000
```

## Publishing

Copy all files into the root of the `aminmsalimi.github.io` repository and push to `main`.
